Teste da skill · constrói o teu eSystem

Instalas a skill /esystem-jornada e constróis a tua plataforma de formação com o Claude. Sais com a plataforma a correr em localhost:3000 e publicada no Vercel.

🔒 Teste
1

MAC · Instala a skill no Terminal

Se estás em Mac: abre a app Terminal. Se já tens o Claude Code aberto, sai primeiro com Ctrl+D. Cola o comando. Enter.

curl -fsSL https://efounder-esystem-teamtest.vercel.app/install-esystem-jornada.sh | bash
Vês ✓ Skill /esystem-jornada instalada → feito.
2

WINDOWS · Instala a skill no PowerShell

Se estás em Windows: abre o PowerShell (procura no menu Iniciar). Se já tens o Claude Code aberto, sai primeiro com Ctrl+D. Cola o comando. Enter. Só fazes 1 dos dois — Mac (em cima) OU Windows (aqui), não os dois.

iex (irm "https://efounder-esystem-teamtest.vercel.app/install-esystem-jornada.ps1")
Vês OK Skill /esystem-jornada instalada → feito.
3

AGORA abre o Claude Code e corre a skill

Só agora, no mesmo Terminal, escreve claude e Enter (fica preto — é o Claude Code · escolhe Sonnet se pedir). Já dentro do Claude Code, escreve o comando em baixo e Enter.

/esystem-jornada
A partir daqui é conversa. Responde só com o número da opção (1, 2, 3). Uma delas está marcada (recomendada).
4

Segue a skill até ao fim

A skill trata de tudo. Vai passar por:

· Buscar o desenho da Missão 2 (do teu Obsidian, colado, ou fazendo 3 perguntas)
· Chapéu de marca (opcional) · Nome · Email · Password inicial
· Clonar o template + patchar textos
· Abrir o Supabase para tu criares projeto e colares 3 chaves
· Criar bucket, conta de mentora, tabelas — sozinha
· Correr localmente e abrir http://localhost:3000
· Publicar no Vercel

Se algo se atrasa (npm install, deploy) — é normal. Aguarda.
5

Confirmar o resultado

No fim tens 2 links a testar:

· http://localhost:3000 — a plataforma no teu computador
· https://xxx.vercel.app — a plataforma no ar (Vercel)

Em ambos, entra como mentora (email + password inicial que deste à skill), vê a jornada, o painel /admin, e testa criar uma aluna.

6

Se algo falhar

Envia à Ana por WhatsApp com:

· Em que passo aconteceu
· Sistema (Mac / Windows) e versão
· Screenshot ou o texto do erro

Bug conhecido a confirmar: em Windows, versões anteriores do script davam erro Unexpected token. A versão atual é diferente — se acontecer, avisar imediatamente.
